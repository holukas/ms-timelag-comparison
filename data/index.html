Data

All datasets live under data/ at the repository root, organized by processing stage. The raw 00-* inputs are tracked in git for provenance; the derived *.parquet files are gitignored, since they are large and can be regenerated from the inputs. This page documents what the directory contains and how it maps onto the processing versions being compared.

Folders are numbered by processing stage. 00-* holds the raw inputs and is never written to; every higher-numbered folder is derived from it and can be regenerated by re-running the notebooks.

  00-eddypro_settings/                        EddyPro project + metadata (input)

  00-pwb_tlag_summary/                        PWB (*-5) tlag summaries (input)

  05-merged_variants_fluxproduct/             variants + product, merged   (notebook x-05, parked)

Notebooks 03 and 04 produce figures, not a numbered data folder. Notebook 03 writes the per-scenario flux and time-lag plots in figures/03_*.png; notebook 04 (the cumulative flux comparison) writes figures/04_cumulative_*.png. The 04- and 05- data folders come from the parked x-04 / x-05 notebooks (see Notebooks).

00-eddypro_fluxes_level-1/¶

EddyPro output in FLUXNET format (one row per half hour, ~9,500 records, 483 columns), one file per processing version. The version code is the leading token of each filename (e.g. QCL-1_eddypro_…_fluxnet_…_adv.csv).

The PWB scenario (QCL-5, LGR-5) has no flux output here yet; only its per-chunk time-lag summaries exist so far (see 00-pwb_tlag_summary/ below). Its flux files will be added to this folder once available.

Columns central to this study:

  • Fluxes: FN2O, FCH4 (and quality/uncertainty companions such as FN2O_RANDUNC_HF, FCH4_RANDUNC_HF).

  • Time-lag diagnostics, per gas. These are the variables the comparison turns on: N2O_TLAG_USED, N2O_TLAG_ACTUAL, N2O_TLAG_NOMINAL, N2O_TLAG_MIN, N2O_TLAG_MAX, and the equivalent CH4_TLAG_* set.

  • Radiation: SW_IN_POT (potential shortwave radiation), used downstream to split fluxes into daytime (SW_IN_POT > 0) and nighttime (SW_IN_POT == 0).

00-eddypro_settings/¶

The EddyPro configuration that produced each flux file: a .eddypro project file and its companion .metadata file per version. Filenames encode the time-lag strategy:

  • *-1_OPENLAG-10s_*: open covariance-maximization search (0 to 10 s), no default fallback (versions *-1).

  • *-2_DEFAULT-10s_*: covariance maximization (0 to 10 s window) with a default fallback lag (versions *-2).

  • *-3_DEFAULT-NARROW_*: covariance maximization over the narrow per-campaign window, default fallback lag (versions *-3).

  • *-4_CH-CHA_…: the earlier (2024) constant-lag runs from the Flux Product (versions *-4).

There are no EddyPro settings for *-5 (PWB); that scenario removes the lag with diive’s detect-and-remove workflow instead (see processing steps). These files are the auditable definition of each version; keep them in sync with the processing versions table.

00-meteo/¶

Meteorological data used as supporting context. To be documented once populated.

00-pwb_tlag_summary/¶

The PWB detect-and-remove output for the *-5 scenario (LGR-5, QCL-5): one *_detect_and_remove_tlag_summary.csv per analyzer, with one row per processed chunk (see processing steps for the method). These hold time-lag results only, not fluxes. The applied lag per gas is {gas}_tlag_final_pf_s. Each CSV ships with a *_columns.md describing every column.

Derived stages (01-…, 02-…, 04-…, 05-…)¶

Generated by the notebooks; safe to delete and regenerate. All are gitignored Parquet.

  • 01-eddypro_fluxes_level-1_parquet/ holds each flux CSV read and re-saved as Parquet, one file per version (LGR-1.parquet, …). Produced by notebook 01.

  • 01-pwb_tlag_summary_parquet/ holds the PWB tlag summaries as Parquet (LGR-5_pwb_tlag.parquet, QCL-5_pwb_tlag.parquet). Only chunks on the 30-minute grid are kept, so they align with the flux timestamps. Produced by notebook 01.

  • 02-eddypro_fluxes_level-1_parquet_subsets/ holds column subsets of the flux Parquets (fluxes, time-lag diagnostics, and SW_IN_POT for the daytime / nighttime split), restricted to the analysis year (2021). Produced by notebook 02.

  • 04-flux-product-2025.3_subset_2024/ holds the year-2024 subset of the final flux product FP2025.3 (CH-CHA, 2005 to 2024), loaded from an external location and used as the independent reference. Produced by notebook x-04 (parked, pending rework for the PWB scenario (*-5)).

  • 05-merged_variants_fluxproduct/ holds the variant subsets merged with the FP2025.3 2024 reference on the timestamp index, each source’s columns suffixed by origin (FN2O_LGR-1, FN2O_FP2025.3, …). Produced by notebook x-05 (parked, pending rework for the PWB scenario (*-5)).
